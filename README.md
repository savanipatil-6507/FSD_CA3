# Full Stack Development (CA3) - Hospital Appointment Management Suite

This repository contains the complete implementation of all 5 assigned programs completed individually in their designated project folders.

---

## Summary of Completed Programs

| Program | Designated Folder | Technology Stack | Key Capabilities |
|---|---|---|---|
| **Program 1** | [`Project1/`](./Project1) | HTML5, CSS3, JavaScript (DOM, Fetch API) | Browser interface, DOM manipulation, input validation, async/await data retrieval, sorting, status updates, simulated HTTP methods (GET, POST, PUT, DELETE). |
| **Program 2** | [`Project2/`](./Project2) | React, JSX, React Router DOM, Vite | Reusable functional components, `useState`, `useEffect`, local persistence, data-entry form, listing view, sorting/filters, and routing. |
| **Program 3** | [`Project3/`](./Project3) | Node.js Core (`http`, `fs`, `path`, `events`, `stream`) | Server-side utility without Express. JSON storage via `fs`/`path`, event notifications with `EventEmitter`, audit log stream, and streaming file exports. |
| **Program 4** | [`Project4/`](./Project4) | Express.js, JWT, bcrypt, CORS | Full REST API with CRUD routes (GET, POST, PUT, DELETE), request logging middleware, input validation middleware, centralized error handling, and JWT-protected routes with bcrypt-hashed passwords. |
| **Program 5** | [`Project5/`](./Project5) | React + Express.js + Sequelize (PostgreSQL/SQLite) | Fullstack integration connecting React UI to Express REST API, database persistence, CORS configuration, environment variables (`.env.example`), and deployment configs for Vercel (frontend) & Render (backend). |
